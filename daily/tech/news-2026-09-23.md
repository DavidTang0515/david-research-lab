### 1. OpenAI 发布 GPT-6 Sol / Luna，模型竞争进入 cost-per-task 阶段

- 领域：AI 模型 / Agent / 企业 AI
- 重要性：高
- 事实概述：OpenAI 9 月 22 日发布 GPT-6 Sol 与 GPT-6 Luna。官方 API 定价显示，Sol 输入 / 输出价格从 GPT-5.6 Sol 的每百万 Token 4 / 20 美元降至 2 / 10 美元；Luna 从 0.20 / 1.20 美元降至 0.10 / 0.50 美元。OpenAI 同时在 AutomationBench、Agents’ Last Exam、DeepSWE 和 OSWorld 等评测中直接披露 cost per task，并改进 prompt caching，缓存输入可享 90% 折扣。官方 benchmark 属于厂商披露，应结合第三方和生产 workload 验证。
- 为什么重要：前沿能力继续提升的同时，模型厂商开始主动把“完成一个真实任务需要多少钱”作为核心竞争指标。对企业而言，这比单纯 Token 单价或 benchmark 分数更接近真实 ROI。
- 长期知识：企业模型评价应逐步采用 `任务成功率 → 单任务 Token / 工具调用 → 时延 → 缓存命中 → 重试 / 人工复核 → 单位成功任务成本 → 业务价值`，而不是只比较每百万 Token 价格。

- 是否进入 Topic：否。属于既有“单位成功任务成本”框架的重要产品验证，等待跨厂商生产数据。

- 重要性：高
- 事实概述：Microsoft 9 月 22 日披露 EvilTokens PhaaS 平台利用 device code authentication flow 诱导用户授权、窃取 Token，并用 AI 辅助生成目标化钓鱼内容和分析失陷邮箱。Microsoft 称该平台自 2026 年 2 月出现后已促成超过 12,000 个邮箱、10,000 多家组织被攻陷；失窃 Token 还可用于邮件外泄、持久化、Microsoft Graph 组织结构侦察和横向移动。

## 4. 对普通人的影响

AI 能力继续快速“降价下放”。更强模型进入中低价格档位后，编码、文档、研究和跨应用任务的使用门槛会继续下降；与此同时，工作技能的重点会从“会不会写 Prompt”转向能否定义任务、检查结果、组织工具和判断 AI 是否真正完成工作。

本地 AI 也开始从隐私卖点变成成本选择。对开发者、创作者和小团队，未来可能出现“固定硬件成本换取不限 Token 的本地智能”与“按量付费云模型”并存的工作方式。

网络安全方面，MFA 仍然必要，但用户需要更警惕 device code、OAuth 授权和异常设备登录。看到要求输入设备验证码或授权陌生应用的页面，不能因为没有输入密码就认为安全。

## 5. 对企业和国企数字化的启示

**第一，把 AI 项目成本口径从 Token 单价升级到单位成功任务成本。** 采购测试应使用真实 OA、知识库、经营分析、编码和流程自动化 workload，同时记录任务成功率、Token、缓存命中、工具调用、时延、失败重试和人工复核成本。

**第二，把“云 / 私有云 / 本地工作站”作为统一部署决策。** 对敏感数据、稳定高频推理、低时延和离线场景，可测算本地高内存工作站或小型集群；对峰值负载、前沿模型和快速迭代任务继续使用云。立项时比较三年 TCO、能耗、运维、模型更新、数据边界和退出成本。

**第三，零信任身份治理要从 MFA 延伸到 Token 和非人身份。** 建议把 OAuth 应用授权、device code flow、Token 生命周期、异常设备注册、Graph / API 权限和 Agent service identity 纳入统一 IAM / SOC 监控，高风险场景支持快速撤销 Token 与会话。

**第四，高风险 AI 的采购条款可以要求“可观测的研发与安全治理”。** 对关键供应商除模型卡外，可关注第三方评估、事故披露、重大版本复测、能力阈值、研发自动化和高风险能力准入机制，避免只用静态等保 / 合规材料判断 AI 风险。

**第五，企业 Agent 应把 Context 与 Harness 当成基础设施。** 企业知识、数据语义、身份、权限、工具调用、人工确认、日志和模型路由应解耦设计，降低单一模型厂商锁定。

## 6. 投资观察

前沿模型价格继续下降，短期有利于企业 AI 应用、Agent 和软件层采用，但也可能通过 Jevons 效应推高总 Token、推理算力、内存和网络需求。端侧高内存设备则为云 AI 之外增加新的算力形态。值得继续观察的不是单一模型发布，而是单位成功任务成本、推理总量、企业付费渗透率以及本地 AI 的真实 TCO。

仅作为趋势观察，不构成投资建议。
